## 🚀 Windows AD Remote Administration Control Center v2.8.0 Enterprise Release

### 🌟 What's New in v2.8.0:
- **⏱️ Inactivity Monitor Update Tracking, Fleet Status Telemetry & Decoupled Ping HUD**:
  - **Fleet Inactivity Status Bar & Interactive Quick-Filter Pills**: Added an interactive status bar directly above the main computer inventory grid featuring real-time fleet counters across six key operational states: `Monitored`, `🟢 Up to Date`, `🟡 Need Update`, `🔴 Failed`, `⚪ Offline`, and `⚫ Not Installed`. Administrators can click any status pill to instantly filter the dashboard view to machines in that specific state, with active visual highlights and a 1-click Reset button to return to the full fleet list.
  - **Dedicated Inactivity Monitor Column & Color-Coded Status Badges**: Added an **Inactivity Monitor** column to the primary inventory data grid displaying clean, color-coded badges with intuitive status icons: `🟢 Up to Date (vX.X)`, `🟡 Update to vX.X`, `🔵 Updating...`, `🔴 Update Failed`, `⚪ Offline / Unchecked`, and `⚫ Not Monitored`. Includes intelligent multi-tier sorting that automatically groups machines needing updates or attention to the top of the grid.
  - **One-Click "⚡ Update All Outdated" Bulk Deployment Action**: When any online computer is detected running an older companion agent version or in an update error state, a prominent action button appears dynamically on the status bar. Clicking this button triggers an automated update process across all eligible online endpoints simultaneously, skipping up-to-date and offline systems.
  - **Decoupled Inactivity Monitor Operations from Network Ping HUD**: Completely removed automatic ping invocations from companion agent installation, update, and uninstallation workflows. Deploying, upgrading, or removing monitoring modules on endpoints now completes seamlessly in the background without triggering or popping open the bottom Ping information panel.
  - **Interactive Update Failure Diagnostics & Quick Retry**: When a companion agent update or deployment encounters an error (such as network timeout, access denial, or RPC failure), right-clicking the endpoint provides a dedicated diagnostic action showing clean root-cause explanations and a direct 1-click retry.
- **🎛️ Dashboard Column Title Filtering, Custom Column Visibility & Preference Persistence**:
  - **Column Title Filtering with Multi-Mode Match Engine & Quick-Select Fleet Pills**: Interactive column filtering added to all 12 dashboard columns (double-click header or right-click to filter). Supports Contains, Equals (Exact Match), Starts With, Does Not Contain, Blanks Only, and Non-Empty Only with quick-select pills of distinct values and active filter indicators (`🔍`).
  - **Custom Column Visibility Checklist & Dynamic Layout Adjustment**: Dedicated Columns visibility menu on the primary toolbar and column header context menus. Check or uncheck individual columns to show or hide them dynamically, with built-in safeguards ensuring at least one column remains visible.
  - **Per-User Column Layout Persistence Across Sessions**: Column visibility configurations are automatically saved to local user application preferences upon change and restored on application startup.
- **🌐 Live Performance Network Adapters IP Address & Interface Telemetry**:
  - **Dedicated IP Address Telemetry & Dual-Stack Network Interface Resolution**: Added an interactive IP Address column to the Live Performance → Network Adapters monitoring grid, dynamically displaying interface-specific IPv4/IPv6 addresses bound to each adapter rather than a single generic system address.
- **📞 Active Directory Phone Number Column & Dynamic Profile Telemetry**:
  - **Direct Directory Profile Phone Retrieval & Grid Integration**: Added a dedicated Phone column to the primary computer inventory grid. Dynamically queries each logged-in user's Active Directory account profile for their phone number, fully indexed in real-time search filtering, sortable, and included in CSV exports.
- **👥 Bulk Active Directory User Profile Attributes Updater (CSV, Excel & Notepad TXT)**:
  - **High-Speed Batch Attribute Updates with Safety Dry-Run Pre-Flight Engine**: Upload CSV, Excel export, or plain text files to update First Name, Initials, Last Name, Display Name, Job Description, Office Location, Telephone Number, and Email Address. Features mandatory read-only pre-flight inspection, strict preservation of blank fields, sample template generator, and audit report exports.
- **🚀 Tools Companion Executable Update Notifications & Streamlined Agent Updates**:
  - **Automatic Detection & In-App Release Notification**: Automatic version detection for the Tools companion executable (`Tools/ADRC_IdleAgent.exe`). Prominent dismissible in-app notification banner highlighting new versions and capabilities with interactive Release Highlights viewer.
  - **Streamlined "Update" Action for Endpoint Inactivity Monitors**: Deployment action in Customization, Automation & Deploy menu selectively upgrades only endpoints running older agent versions, skipping systems already up to date.
- **🌐 Dynamic Active Directory Domain Switcher & Custom Forest Discovery**:
  - **Multi-Domain Navigation and Manual Forest Targeting**: Domain discovery banner upgraded into an interactive selection menu discovering accessible AD domains and forest trusts, with manual domain entry and instant refresh.
- **🛡️ Enterprise Remote Power & Workstation Lock Reason Confirmation**:
  - **Operational Auditing, Reason Tracking & Safety Countdown**: Dedicated confirmation window requiring a documented operational reason (System Updates, Hardware Maintenance, Troubleshooting, Power Conservation, Security Incident, Scheduled Maintenance, Custom Notes) with countdown grace periods and force-close options.
- **🎯 Dynamic Multi-Selection Inventory Counter & Action Toolbar Badges**:
  - **Live Selection Counters and Target Badge Indicators**: Selecting multiple computers dynamically updates bottom counters and quick-action toolbar badges (e.g. `🔄 Restart (3)`, `🛑 Shutdown (3)`, `🔒 Lock Screen (3)`, `🖼️ Wallpaper (3)`).
- **🖥️ Remote Display & Monitor Power Management (`Turn Off Monitor`)**:
  - **Instant Remote Display Power-Down & Energy Optimization**: Native remote monitor standby power-saving control (`Turn Off Monitor (Power Saving)` and `Turn Off Monitors (Bulk)`) to securely blank remote displays and conserve power.
- **🔒 Dual-Layer Session-Safe Physical Mouse & Keyboard Input Lock (`Block Mouse & Keyboard Input`)**:
  - **Hardware-Level Local Input Suppression**: Suppresses physical USB and PS/2 mouse and keyboard hardware while strictly preserving virtual Remote Desktop input devices. Features a 30-minute safety timeout watchdog and instant toggle restoration.
- **🔓 Direct Credential Session Unlock (`Remote Workstation Lock & Unlock Controller`)**:
  - **Silent Password-Based Workstation Unlock**: Silent credential-based session unlock directly on the target physical console without intrusive prompts.
- **📊 Remote Group Policy HTML Diagnostic Report (`Generate GPResult Report`)**:
  - **Interactive In-Browser Group Policy Audit**: 1-click diagnostic tool generating a complete HTML Group Policy result report on any domain endpoint, opening immediately in the default browser.
- **🔓 Real-Time Remote Desktop Status Probing & Dynamic Visual Indicator**:
  - **Live Discovery and Polling of Endpoint Remote Desktop Accessibility**: Real-time port 3389 reachability verification with distinct visual badges (🟢 Remote Desktop Active / 🔴 Remote Desktop Disabled / ⚪ Offline) and tooltip diagnostics.
- **📡 Interactive In-App Ping Telemetry HUD, Layer 2 Diagnostics & Route Inspector**:
  - **Continuous Real-Time Ping Telemetry**: Live ping stream at 1-second intervals with dynamic `⏹ Stop Ping` / `▶️ Ping` toggle and instant diagnostic clearance upon dismissal.
  - **Sliding Telemetry Diagnostics HUD with 4 Views**: Quick Metrics, Hop Traceroute with scrollable viewport containment, Layer 2 (MAC & NIC) hardware inspector, and Live Pulse sparkline graph.
