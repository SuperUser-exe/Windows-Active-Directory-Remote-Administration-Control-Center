## [Release] Windows AD Remote Administration Control Center v2.9.0 Enterprise Release

### What's New in v2.9.0:
- **[Credentials] Active Directory User Credentials Validation & Diagnostics Controller**:
  - **Non-Interactive Credential Verification & Login Diagnostics**: Added a dedicated Active Directory User Credentials Tester accessible directly from the Quick Actions toolbar and right-click context menu. Administrators can enter any domain username and password to safely verify credentials against the domain controller without requiring the user to log in or initiate a remote session.
  - **Instant Visual Outcome & Diagnostic Status Reporting**: Implemented clear, color-coded outcome badges and descriptive messages confirming whether authentication succeeded (`[Valid Credentials - Authentication successful]`) or failed (`[Invalid Credentials - Authentication failed: Invalid username or password]`), removing guesswork when diagnosing password-related issues.
  - **Integrated Account Lockout Detection & 1-Click Unlock**: Added real-time account lockout detection that immediately alerts administrators if an account is locked out in Active Directory due to repeated incorrect password attempts, accompanied by a prominent 1-click `[Unlock Account Now]` button to immediately clear the lockout and re-test credentials.
  - **Comprehensive Account Identity Overview & Password Lifecycle Details**: Displays full directory identity details upon lookup, including User Display Name, User Principal Name (UPN), SAM Account Name, Account Status (Enabled or Disabled), Lockout Status, Password Last Set timestamp, Password Expiration policy status, and the Authenticating Domain Controller.
  - **Password Visibility Toggle & Ergonomic Input Controls**: Added an interactive visibility eye toggle (`[Show] / [Hide]`) to inspect complex special characters and prevent typos, clipboard paste support, pre-filling of the currently selected workstation's logged-in user, and quick clear controls.

- **[Network] Remote Network Profile Management (Public / Private Network Switch)**:
  - **Real-Time Network Profile Category Diagnostic & Inspection**: Added real-time remote inspection of network profile categories across client workstations. Support personnel can view the active status of every connected network adapter (Ethernet, Wi-Fi, virtual connections) and determine whether the network is classified as Public, Private, or Domain-Authenticated.
  - **1-Click Remote Public / Private Network Switching**: Implemented 1-click remote switching between Public and Private network categories. Technicians can switch individual network adapters or switch all active connections on the remote computer to Private in a single operation, immediately resolving issues where Windows erroneously defaults an office network to "Public", unblocking Network Discovery, Windows File Sharing, and local network printers in seconds.
  - **Fleet-Wide Bulk Network Profile Management**: Enabled multi-computer network profile management across bulk workstation selections. Administrators can view network category statuses across dozens of machines simultaneously and apply Private or Public classifications fleet-wide with live progress tracking and summary reporting.
  - **Automatic Domain Network Protection & Troubleshooting Guidance**: Integrated automatic safeguards that protect Active Directory Domain networks from accidental reclassification, along with a built-in operational guidance panel explaining firewall impacts and providing 1-click clipboard diagnostic scripts.

- **[Filesystem] Win32 Long Path Support Manager & Real-Time Filesystem Policy Controller**:
  - **Real-Time Long Path Status Diagnostic & Verification**: Added comprehensive real-time detection for Windows Win32 long path support across local workstations and remote network computers. The diagnostic engine queries both system filesystem configuration parameters and Windows Group Policy settings to determine whether deep directory paths exceeding the standard 260-character limitation are enabled.
  - **1-Click Local and Fleet-Wide Long Path Enablement**: Implemented automated 1-click enablement and restoration of Win32 long path support across single or bulk selected workstations, configuring operating system filesystem registry and policy settings simultaneously so deep folder hierarchies up to 32,767 characters navigate without errors.
  - **Interactive PowerShell Script Generator & Safety Guidance**: Integrated a dedicated interactive management dialog with 1-click clipboard script copying, real-time status indicators, operational safety recommendations (such as utilizing dry-run testing modes during file cleanup procedures), and integration with Windows God Mode & Power Tweaks.

- **[Remote Desktop] High-Fidelity Remote Desktop Status Engine & Persistent Port Detection**:
  - **Direct IP Port 3389 Probing Architecture**: Redesigned the Remote Desktop detection engine to directly probe endpoint IP addresses on port 3389, bypassing DNS resolution latency and decoupling port status verification from remote management service connectivity.
  - **Persistent Cache Storage & Instant Startup Loading**: Added Remote Desktop capability tracking to the local directory cache, preserving connection indicators across application restarts for immediate visual readiness.
  - **Telemetry Synchronization & Dynamic Refresh**: Integrated port detection into real-time ping telemetry and endpoint diagnostics. When inspecting or pinging an endpoint, the inventory badge updates dynamically to reflect live network accessibility.

- **[Screen Shadow] Intelligent Remote Shadow & Terminal Services Self-Healing Engine**:
  - **Automated Remote Service Validation & Self-Healing**: Implemented automated diagnostic and self-healing mechanisms for Remote Desktop screen shadowing. Prior to initiating mirror sessions, the system verifies that the target workstation's terminal services components are healthy, connection policies are enabled, and required service dependencies are properly registered. Missing or corrupted configurations are automatically restored and idle services are seamlessly started.
  - **Proactive Port and Listener Readiness Check**: Added background listener verification before dispatching screen connection requests. If the remote service is stopped or the listener is inactive, the system initiates the service remotely and ensures the port is actively listening before presenting the connection window, preventing connection timeouts.

- **[Security] Domain-Joined PC Enforcement & Redesigned Access Restriction Architecture**:
  - **Strict Active Directory Domain-Joined Computer Requirement**: Enforced strict enterprise security policy verifying that the host workstation executing the suite is joined to an authenticated Active Directory domain, blocking execution on unauthorized standalone or workgroup machines.
  - **Comprehensive Diagnostic Breakdown & Visual Guidance**: Replaced standard modal alert dialogs with a high-density, centered diagnostic window clearly explaining domain status, workgroup classification, and security guidelines.
