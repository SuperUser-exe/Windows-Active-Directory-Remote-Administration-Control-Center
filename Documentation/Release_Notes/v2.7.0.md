## 🚀 Windows AD Remote Administration Control Center v2.7.0 Enterprise Release

### 🌟 What's New in v2.7.0:
- **🎨 Modern Windows 11 Fluent Icon & Transparent Silhouette**: High-resolution Fluent-styled application icon with transparent silhouette that integrates naturally into light and dark Windows 11 taskbars, eliminating dark backdrop borders.
- **📂 Company-Internal Network File Share Auditing & Incident Extraction**: Structured entity resolution in Remote Event Log Viewer for user account, source workstation/IP, network share location, specific file name, and action taken, keeping all audit details 100% local and company-internal.
- **🎯 Remote Event Viewer Deep Entity Search & Authoritative Scope**: Authoritative date-ranged forensic search across users, workstations, IP addresses, and file paths across remote machines without display limit constraints.
- **📅 Custom Date & Time Range Filtering with High-Performance Traversal**: Precision date-time pickers for forensic investigations with early termination for ultra-fast query execution on busy domain controllers.
- **🖨️ Real-Time Remote Printer Queue Monitor & Consumable Indicators**: Sub-second live print queue streaming, multi-color ink and toner level indicators with standardized 6-tier severity scaling (Cyan, Magenta, Yellow, Black) and automated domain network address resolution.
- **📊 Per-User Printing Report & Fleet Consumption Analytics**: Centralized domain print server discovery, multi-dimensional user/workstation filtering, job lifecycle tracking (completed, failed, cancelled), and executive printable HTML reports.
- **⏰ Scheduled Remote Power Operations**: Interactive scheduling for remote reboot, shutdown, logoff, and workstation lock with customizable user warning countdowns and single-click cancellation.
- **🖥️ Remote Screen Saver & Central Desktop Wallpaper Manager**: Theme-adaptive configuration of inactivity timeouts, password lock upon resume, and bulk branded desktop wallpaper deployment across domain machines.
- **💬 On-Screen Message Delivery & User Acknowledgement Tracker**: Urgent broadcast messaging with real-time delivery status, logged-in username tracking, and per-user read/acknowledgement receipts.
- **📈 Unified Live Performance Monitor & Full-Screen Deep Telemetry**: Consolidated hardware and subsystem diagnostics (motherboard, RAM DIMMs, storage health) with expandable 10-minute rolling history graphs, KPI cards, and 1-click system specs clipboard export.
- **🔓 Remote Desktop (RDP) Enablement & Diagnostic Center**: Automated pre-flight TCP 3389 reachability check, one-click service enablement and firewall configuration, and bulk RDP activation across multiple endpoints.
- **🔑 Windows LAPS & Local Administrator Password Management Suite**: Modern encrypted Windows LAPS attribute decryption, plaintext viewing with clipboard copy, instant 1-click rotation ("Expire Now"), and visual expiration scheduling with live countdowns.
- **🛡️ Enterprise Security Policies & Multi-Tier Lockout Governance**: Dynamic policy screens with incident reference tracking, scoped emergency unlock requests, and domain administrator authorization verification.
- **⚡ Workstation Right-Click Context Menu Fast Action Search**: Real-time type-to-filter search bar across all administration tools and bulk operations, with target device status headers and streamlined categorization.
- **⏱️ Inactivity & Presence Monitoring Agent Health & Multi-Tier Diagnostics**: 4-state diagnostic health model (Active, Inactive, Not Installed, Offline) with automated service recovery, high-contrast visual status badges, and clean multi-stage remote agent teardown.
- **🗑️ Local Computer Users & Security Manager Safeguards**: Secure user account deletion with administrative password confirmation, protection shields against deleting core system accounts, and show/hide password toggles.
- **⏱️ Remote System Restore Point Manager**: Checkpoint creation, restore history timeline, and remote machine recovery with automatic restart confirmation.
- **⚡ Remote Network Adapter One-Click Repair & Reset Suite**: Resilient multi-stage network reset (DNS flush, Winsock reset, TCP/IP stack overhaul, adapter restart, DHCP release/renew) that reliably completes even during temporary disconnection.
